# ÉLAN — Capsule Wardrobe & Fashion Advisor

Учебный веб-проект, созданный на основе предоставленных `index.html`, `style.css`, `script.js`. Исходники сохранены как `original-*`.

## Запуск

1. Установите Node.js 18+.
2. Откройте папку `ModaCapsule_PRO` в VS Code.
3. В терминале запустите `npm start` (никаких `npm install` не требуется).
4. Откройте http://localhost:3000

Не используйте Live Server: регистрация и вход работают через встроенный Node.js сервер.

## Возможности

- Новый адаптивный дизайн ÉLAN Style Studio.
- Регистрация и вход: пароль хешируется `scrypt`, сессия хранится в HttpOnly-cookie.
- Личный кабинет со статистикой и сохранёнными образами.
- Капсульный гардероб: 14 стартовых вещей, добавление, удаление, категории.
- Генератор образов по погоде, событию и эстетике.
- Стиль-консультация по цели, эстетике и бюджету, сохранение результатов.
- Smart Shop: внешние поисковые ссылки Kaspi, без проверки наличия/цен.

## Данные и безопасность

Зарегистрированные пользователи хранятся локально в `data/users.json` (автоматически создаётся при регистрации). Файл исключён из Git через `.gitignore`. Не публикуйте его. Проект предназначен для локальной демонстрации: сессии хранятся в памяти сервера, HTTPS, восстановление пароля, защита от перебора и production-хранилище не реализованы. Консультации генерируются правилами, не являются рекомендациями профессионального стилиста или AI-чатом.

Фото из Unsplash и шрифты Google Fonts требуют подключения к интернету.
